# 단체 대회 앱 · 운영진용 UX 안내 (철원 예시)

날짜: 2026-08-06  
대상: 동마클 운영진 (비IT)  
미리보기 HTML: `event-cheorwon-ops-preview.html`  
로컬: `http://localhost:5000/event-cheorwon-ops-preview.html`

> 화면·인원·시각은 **이해를 위한 가상 예시**입니다. 실제 철원 공지와 다를 수 있습니다.

---

## 한 줄로

**당일 시작점은 버스 탑승.**  
그다음 배번 입력 → 같이 뛸 사람 찾기 → 같이 뛰기 → 복귀·결과 확인.  
카페 설문은 그대로, 앱은 **당일 탑승·배번·페이스 매칭·기록**에 집중합니다.

---

## 회원 흐름 (당일)

1. **새벽에 버스 탭에서 가는 버스 탑승 체크** (링크/QR).  
2. **버스에 탄 뒤(이동 중) 배번·종목 입력** → 참가 명단 반영. 목표 시간은 선택.  
3. **명단·결과**에서 같은 종목·비슷한 목표 시간의 회원을 찾는다. (실명·배번 숫자 비공개)  
4. 같이 뛰고, **오는 버스**도 체크한다.  
5. **돌아오는 길**에 명단·결과에서 기록을 확인한다. PB는 본인이 홈에서 표시할 수 있다.

사전 배번 입력도 가능하지만, 운영진 설명·당일 스토리의 주인공은 위 순서입니다.

---

## 화면 구성 (회원용)

| 탭 | 하는 일 |
|----|---------|
| 홈 | 내 참가 정보(배너) · 당일 일정 · 배번 입력 |
| 버스 | 가는/오는 탑승 체크 · 탑승 현황 목록 |
| 명단·결과 | 닉·종목·목표시간 → 이후 기록. 검색·종목 필터·정렬 |

---

## 운영진 역할 (구분)

- **카페 설문:** 누가 나가나, 버스·중식 등 (기존)  
- **앱 관리(별도 화면):** 버스 명단 준비, 기록 취합·확정 등  
- **이 미리보기:** 회원 화면만 보여 줍니다.
