# v0.21.4 — 배번 페이지 출발 그룹·목표 시간

> **상태:** 배포 전. 태그는 배포가 성공한 뒤에만 `v0.21.4`.
> **이전 노트:** `v0.21.3`
> **앱 버전:** `cheer/bib.html`만 `<meta name="app-version" content="0.21.4">`. `noindex`와 상단 목적 문구는 유지한다.

PATCH다. 풀코스 배번 화면의 조 선택과 목표 시간 입력만 바꾼다. 저장은 기존 `update-bib`이고, 목표는 그대로 `goalFinishSec`(1–10시간)다. 배번은 저장 후에도 고칠 수 있다.

- 출발 그룹이 1개 이상이면 칩으로 항상 보인다. 조 이름이 크고, 시각은 출발 순서를 가늠하는 작은 글씨다.
- 그룹이 없으면 칩 대신 "출발 그룹이 아직 없습니다"만 보인다. 배번과 목표는 저장된다.
- 완주 목표는 `시:분:초` 한 줄이다. 숫자 키패드, 두 자리(시는 2–9면 한 자리) 뒤 다음 칸, 평균 페이스 미리보기.

## 배포

Hosting만 필요하다. `functions:race`, `functions-all`, Storage는 필요 없다.

```bash
firebase deploy --only hosting --project dmc-attendance
```

```bash
curl -sS "https://dmc-attendance.web.app/cheer/bib.html" | grep -F 'id="waveChips"'
curl -sS "https://dmc-attendance.web.app/cheer/bib.html" | grep -F '배번과 완주 목표 시간을 입력해 주세요. 실시간 응원과 기록 수집에 쓰입니다.'

```
