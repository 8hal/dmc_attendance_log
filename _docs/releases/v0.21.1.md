# v0.21.1 — 응원 레디샷 제거

> **이후 변경 (v0.21.2):** 배번 페이지 안내 두 줄을 목적 한 줄로 바꿨다. `_docs/releases/v0.21.2.md`

> **상태:** 배포 전. 태그는 배포가 성공한 뒤에만 `v0.21.1`.
> **이전 태그:** `v0.21.0`
> **앱 버전:** 응원 화면 `<meta name="app-version" content="0.21.1">`. `noindex`는 유지한다.

PATCH다. `v0.21.0`에 넣은 레디샷(배번 사진 업로드, OCR, 응원 상세 표시)을 뺀다. JTBC 대회 배번 사진(배번 10947)을 읽지 못해 기능을 쓰지 않기로 했다. 배번·종목·조·완주 목표는 직접 입력과 기존 `update-bib` 저장을 그대로 쓴다.

이미 저장된 `readyShotUrl`은 지우지 않는다. 마이그레이션은 없다. 명단을 다시 저장해도 그 필드는 남긴다. 응원 API와 화면은 그 주소를 보여 주지 않는다.

## 배포

Hosting만으로는 부족하다. 예전 `race` 함수는 사진 업로드를 받고 상세 응답에 `readyShotUrl`을 넣는다.

- 필요: `hosting`과 `functions:race`
- `functions-all`은 필요 없다. 스케줄 함수 동작은 바뀌지 않았다. Actions에서는 `functions-attendance-race`가 `race`를 포함한다. hosting은 그다음 별도로 올린다.
- Storage 배포는 필요 없다. `cheer/ready-shots` 규칙은 운영에 올라간 적이 없고, 저장소 규칙에서도 뺐다.

```bash
firebase deploy --only functions:race --project dmc-attendance
firebase deploy --only hosting --project dmc-attendance
```

### 배포 후 확인

```bash
curl -sS "https://dmc-attendance.web.app/cheer/bib.html" | grep -E 'app-version|noindex'
curl -sS "https://dmc-attendance.web.app/cheer/bib.html" | grep -E '레디샷|cheer-bib-ocr|readyShot' && exit 1 || true
curl -sS "https://dmc-attendance.web.app/cheer/index.html" | grep -E 'shotLightbox|레디샷|readyShot' && exit 1 || true
```

배번 페이지에 파일 선택과 레디샷 문구가 없고, 배번 칸과 저장이 있다. 응원 상세에는 사진 영역이 없다.

### 태그 (배포 성공 후)

```bash
git tag -a v0.21.1 -m "응원 레디샷 업로드와 OCR 제거"
git push origin v0.21.1
```
