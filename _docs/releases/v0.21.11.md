# v0.21.11 — 배번 요약에 출발 그룹·완주 목표

> **상태:** 배포 전. 태그는 배포가 성공한 뒤에만 `v0.21.11`.
> **이전 노트:** `v0.21.10`

PATCH다. 회원 홈(`event-home.html`)에서 배번을 저장한 뒤 보이는 큰 배번 카드 아래에, 풀코스일 때 두 줄을 더 보여 준다.

- `출발 그룹 A` — 조 이름(A–H)만 보인다. 조 출발 시각은 나오지 않는다. 조를 안 골랐으면 `출발 그룹 미선택`.
- `완주 목표 3:30:00 · 4:58/km` — 목표가 없으면 `완주 목표 미입력`.
- 풀코스가 아니면 두 줄 모두 숨긴다.
- 값은 기존 `EventBibForm.savedBibSummary`(`waveId`, `goalFinishSec`)에서 읽는다. 저장 API(`update-bib`)는 그대로다.
- 배번 숫자만 입력(v0.21.10), 코스 탭 닉네임만, 배번·보드 실명 표시, 하단 응원 탭은 바꾸지 않는다.
- `cheer/bib.html` 저장 요약은 이미 조·목표를 보여 주므로 바꾸지 않았다.

## 배포

Hosting만 필요하다. `functions:race`, `functions-all`, Storage는 필요 없다.

```bash
firebase deploy --only hosting --project dmc-attendance
```
