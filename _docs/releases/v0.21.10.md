# v0.21.10 — 배번은 숫자만

> **상태:** 배포 전. 태그는 배포가 성공한 뒤에만 `v0.21.10`.
> **이전 노트:** `v0.21.9`
> **앱 버전:** `cheer/bib.html`만 `<meta name="app-version" content="0.21.10">`. `cheer/index.html`은 `0.21.9` 그대로다. `noindex`는 유지한다.

PATCH다. 실물 배번에 `A-1037`처럼 조 글자가 붙어 있어도, 배번 칸에는 숫자만 넣게 안내한다. 입력은 숫자만 받는다.

- 배번 칸 아래: `실물 배번에 A-1037처럼 글자가 있어도 숫자만 넣으세요. 예: 1037`
- `A-1037`을 붙여 넣으면 `1037`만 남는다. 글자·하이픈은 입력 중에 빠진다. 저장할 때도 숫자만 보낸다.
- 저장 후 요약 카드: `숫자만 저장됩니다. A-1037이면 1037입니다.`
- 출발 그룹(A–H) 이름만 보인다. 조 출발 시각은 나오지 않는다. 실명(`닉네임 · 실명`)도 그대로다. 코스 탭은 닉네임만이다.
- `update-bib`는 빈 문자열만 거절하고, 글자를 지우거나 막지 않는다. 클라이언트가 숫자만 보낸다. Functions 배포는 필요 없다.

## 배포

Hosting만 필요하다. `functions:race`, `functions-all`, Storage는 필요 없다.

```bash
firebase deploy --only hosting --project dmc-attendance
```

### 배포 후 확인

```bash
curl -sS "https://dmc-attendance.web.app/cheer/bib.html" | grep -F 'content="0.21.10"'
curl -sS "https://dmc-attendance.web.app/cheer/bib.html" | grep -F '실물 배번에 A-1037처럼 글자가 있어도 숫자만 넣으세요. 예: 1037'
curl -sS "https://dmc-attendance.web.app/cheer/bib.html" | grep -F '숫자만 저장됩니다. A-1037이면 1037입니다.'
curl -sS "https://dmc-attendance.web.app/cheer/bib.html" | grep -F 'EventBibForm.bibDigits'
curl -sS "https://dmc-attendance.web.app/cheer/index.html" | grep -F 'content="0.21.9"'
```
