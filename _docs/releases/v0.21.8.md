# v0.21.8 — 회원 홈 응원 탭

> **상태:** 배포 전. 태그는 배포가 성공한 뒤에만 `v0.21.8`.
> **이전 노트:** `v0.21.7`
> **앱 버전:** cheer 페이지 메타는 `0.21.7` 그대로다. `cheer/bib.html`, `cheer/index.html`, `cheer/waves.html`은 이번 변경에 없다. `noindex`도 유지한다.

PATCH다. 단체대회 회원 홈에서 응원 카드(`#cheerLinkCard`)를 뺀다. 응원 보드는 하단 탭의 세 번째 칸이다.

- `event-home.html`과 `event-roster.html`의 `nav#eventTabBar`에 `응원` 탭을 둔다. 아이콘은 `📣`. 누르면 `cheer/index.html?eventId=`로 이동한다. 홈·대회 기록 탭의 활성 표시와는 따로 둔다.
- 탭은 풀코스 선수만의 화면이 아니다. 가족·자원봉사자를 포함해 탭바가 보이는 사람에게 그대로 보인다.
- `목표·조 수정` 링크는 없앤다. 저장된 배번이 있는 내 정보 카드의 `#profileEditBtn`이 그 역할이다. 종목이 `full`이면 버튼 이름은 `배번·목표 수정`, 그 외에는 `배번 수정`이다. 풀코스 배번 폼의 조(A~H, 시각 없음)와 목표 시간은 그대로다.
- 배번 화면·응원 보드의 실명 표시(`닉네임 · 실명`)와 조 출발 시각을 숨기는 동작은 바꾸지 않는다.

## 배포

Hosting만 필요하다. `functions:race`, `functions-all`, Storage는 필요 없다.

```bash
firebase deploy --only hosting --project dmc-attendance
```
