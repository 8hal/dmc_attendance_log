# v0.21.9 — 코스 탭은 닉네임만

> **상태:** 배포 전. 태그는 배포가 성공한 뒤에만 `v0.21.9`.
> **이전 노트:** `v0.21.8`
> **앱 버전:** `cheer/index.html`만 `<meta name="app-version" content="0.21.9">`. `cheer/bib.html`은 `0.21.7` 그대로다. `noindex`는 유지한다.

PATCH다. 응원 보드 코스 탭에서는 실명을 빼 닉네임만 보여 준다. 지도에 실명까지 있으면 보기가 불편하다.

- 코스 위 이름과, 같은 지점에 여러 명이 있을 때 고르는 버튼은 닉네임만이다. 겹치면 `닉네임 +숫자`다.
- 순위 목록과 선수 상세는 `닉네임 · 실명`을 유지한다.
- 배번 화면의 요약·입력도 `닉네임 · 실명`을 유지한다. 닉네임 선택 목록은 닉네임만이다.
- `cheer-board`와 `cheer-runner`의 `realName`은 그대로다. 순위와 상세가 쓴다.
- 조 출발 시각은 나오지 않는다.

## 배포

Hosting만 필요하다. `functions:race`, `functions-all`, Storage는 필요 없다.

```bash
firebase deploy --only hosting --project dmc-attendance
```

### 배포 후 확인

```bash
curl -sS "https://dmc-attendance.web.app/cheer/index.html" | grep -F 'content="0.21.9"'
curl -sS "https://dmc-attendance.web.app/cheer/index.html" | grep -F 'const name = lead[0].nickname'
curl -sS "https://dmc-attendance.web.app/cheer/index.html" | grep -F 'runnerLabel(lead[0])' && exit 1 || true
curl -sS "https://dmc-attendance.web.app/cheer/index.html" | grep -F 'bibIdentityLine'
curl -sS "https://dmc-attendance.web.app/cheer/bib.html" | grep -F 'content="0.21.7"'
```

### 태그 (배포 성공 후)

```bash

git push origin v0.21.9
```
