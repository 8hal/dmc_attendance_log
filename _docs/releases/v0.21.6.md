# v0.21.6 — 배번 저장 후 요약

> **상태:** 배포 전. 태그는 배포가 성공한 뒤에만 `v0.21.6`.
> **이전 노트:** `v0.21.5`
> **앱 버전:** `cheer/bib.html`만 `<meta name="app-version" content="0.21.6">`. `noindex`는 유지한다.

PATCH다. `cheer/bib.html`에서 배번을 저장하면 입력 폼 대신 요약을 보여 준다. 이미 배번이 있는 참가자가 링크로 다시 오면 요약이 먼저 나온다. 저장은 기존 `update-bib`다.

- 배번은 홈과 같은 배번판으로 크게 보인다.
- 풀코스는 그 아래 출발 그룹 이름과 `시:분:초 · 페이스` 한 줄이다. 조별 시각은 나오지 않는다.
- `응원 보드 보기`는 큰 버튼이고, `배번·목표 수정`을 누르면 같은 폼이 저장된 값으로 다시 열린다. 배번은 언제든 고칠 수 있다.
- 풀코스가 아니면 배번과 짧은 안내만 있다. 응원 보드는 보러 갈 수 있고, 수정 버튼은 `배번 수정`이다.

## 배포

Hosting만 필요하다. `functions:race`, `functions-all`, Storage는 필요 없다.

```bash
firebase deploy --only hosting --project dmc-attendance
```

### 배포 후 확인

```bash
curl -sS "https://dmc-attendance.web.app/cheer/bib.html" | grep -F 'content="0.21.6"'
curl -sS "https://dmc-attendance.web.app/cheer/bib.html" | grep -F 'id="savedBoard"'
curl -sS "https://dmc-attendance.web.app/cheer/bib.html" | grep -F '배번·목표 수정'
curl -sS "https://dmc-attendance.web.app/cheer/bib.html" | grep -F 'id="done"' && exit 1 || true
```

### 태그 (배포 성공 후)

```bash
git tag -a v0.21.6 -m "배번 저장 후 요약 카드"
git push origin v0.21.6
```
