# v0.21.2 — 배번 페이지 안내 한 줄

> **상태:** 배포 전. 태그는 배포가 성공한 뒤에만 `v0.21.2`.
> **이전 태그:** `v0.21.1`
> **앱 버전:** `cheer/bib.html`만 `<meta name="app-version" content="0.21.2">`. `noindex`는 유지한다.

PATCH다. 배번 페이지에서 아래 안내와, 출발 시각이 없을 때만 첫 문장을 보이던 조건을 뺐다.

- 아직 출발 시각이 등록되지 않았습니다. 지금 넣어 두면 등록 후 응원 보드에 나옵니다.
- 조와 목표를 비워도 배번은 저장됩니다. 완주 목표 시간을 넣으면 응원 보드에 나옵니다.

제목 아래 한 줄로 바꾼다. "배번과 완주 목표 시간을 입력해 주세요. 실시간 응원과 기록 수집에 쓰입니다."

저장 요청과 `update-bib`는 그대로다. 저장 후 안내 문장도 바꾸지 않았다.

## 배포

Hosting만 필요하다. `functions:race`와 `functions-all`, Storage는 필요 없다.

```bash
firebase deploy --only hosting --project dmc-attendance
```

### 배포 후 확인

```bash
curl -sS "https://dmc-attendance.web.app/cheer/bib.html" | grep -F '배번과 완주 목표 시간을 입력해 주세요. 실시간 응원과 기록 수집에 쓰입니다.'
curl -sS "https://dmc-attendance.web.app/cheer/bib.html" | grep -E '아직 출발 시각이 등록되지 않았습니다|조와 목표를 비워도 배번은 저장됩니다' && exit 1 || true
```

### 태그 (배포 성공 후)

```bash
git tag -a v0.21.2 -m "배번 페이지 안내를 목적 한 줄로 정리"
git push origin v0.21.2
```
