# v0.21.3 — 회원 홈에서 응원 보드로

> **상태:** 배포 전. 태그는 배포가 성공한 뒤에만 `v0.21.3`.
> **이전 노트:** `v0.21.2`
> **앱 버전:** cheer 페이지 메타는 그대로다. 이번 변경은 `event-home.html` 링크뿐이다.

PATCH다. 닉네임이 확정된 회원 홈(`event-home.html`의 `#home`)에 버튼 두 개를 둔다.

- 응원 보드 → `cheer/index.html?eventId=`
- 풀코스 목표 입력 → `cheer/bib.html?eventId=&nickname=` (참가자 종목이 `full`일 때만)

버스 QR(`boarding.html` → `event-home.html?board=1`)은 탑승 처리 후 같은 홈을 연다. 버튼은 그 홈에 있다. 홈에 있는 동안 `cheer-board` / `cheer-runner`는 호출하지 않는다. 탑승·배번·확정 저장은 그대로다. `/cheer/` 공개 주소와 `event-admin` QR도 그대로다.

## 배포

Hosting만 필요하다. `functions:race`, `functions-all`, Storage는 필요 없다.

```bash
firebase deploy --only hosting --project dmc-attendance
```

### 배포 후 확인

```bash
curl -sS "https://dmc-attendance.web.app/event-home.html" | grep -F 'id="cheerBoardLink"'
curl -sS "https://dmc-attendance.web.app/event-home.html" | grep -F 'cheer/index.html'
curl -sS "https://dmc-attendance.web.app/event-home.html" | grep -F '풀코스 목표 입력'
curl -sS "https://dmc-attendance.web.app/event-home.html" | grep -E 'cheer-board|cheer-runner' && exit 1 || true
```

### 태그 (배포 성공 후)

```bash
git tag -a v0.21.3 -m "회원 홈에서 응원 보드와 풀코스 목표 입력으로 이동"
git push origin v0.21.3
```
