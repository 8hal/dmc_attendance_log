# v0.21.5 — 홈 풀코스 목표·출발 그룹

> **상태:** 배포 전. 태그는 배포가 성공한 뒤에만 `v0.21.5`.
> **이전 노트:** `v0.21.4`
> **앱 버전:** `cheer/bib.html`만 `<meta name="app-version" content="0.21.5">`. `noindex`는 유지한다.

PATCH다. 응원은 풀코스만 하므로, 회원 홈에서 풀코스를 고르면 배번과 함께 완주 목표와 출발 그룹을 받는다. 저장은 기존 `update-bib`다. 목표는 `goalFinishSec`(1–10시간)이고, 그룹은 `waveId`다. 배번은 저장 후에도 고칠 수 있다.

- 홈에서 풀코스가 아니면 지금까지처럼 배번만 넣는다.
- 풀코스면 출발 그룹은 이름 칩만 보인다. 조별 시각은 선수 화면에 나오지 않는다. 그룹이 없으면 "출발 그룹이 아직 없습니다"만 보인다.
- 완주 목표는 `시:분:초` 한 줄이고, 평균 페이스가 옆에 나온다. 비우면 저장되지 않는다.
- 이미 넣은 배번·목표·그룹은 수정 화면에 다시 채워진다.
- `cheer/bib.html`에서는 종목을 고르지 않는다. 종목이 없거나 풀코스면 풀코스로 저장한다. 다른 종목이면 한 줄로 알리고 배번만 고친다.
- 홈의 `풀코스 목표 입력`은 `목표·조 수정` 링크다. 응원 보드 링크는 그대로다.
- 응원 보드 상세에도 조 출발 시각을 찍지 않는다. 조 이름만 보인다.

## 배포

Hosting만 필요하다. `functions:race`, `functions-all`, Storage는 필요 없다. 서버의 `update-bib` 검증은 그대로다.

```bash
firebase deploy --only hosting --project dmc-attendance
```

### 배포 후 확인

```bash
curl -sS "https://dmc-attendance.web.app/cheer/bib.html" | grep -F 'content="0.21.5"'
curl -sS "https://dmc-attendance.web.app/cheer/bib.html" | grep -F 'id="notFullNote"'
curl -sS "https://dmc-attendance.web.app/cheer/bib.html" | grep -E 'id="distChips"|data-dist' && exit 1 || true
curl -sS "https://dmc-attendance.web.app/event-home.html" | grep -F '목표·조 수정'
curl -sS "https://dmc-attendance.web.app/event-home.html" | grep -F 'id="profileGoalH"'
curl -sS "https://dmc-attendance.web.app/event-home.html" | grep -F '풀코스 목표 입력' && exit 1 || true
```
