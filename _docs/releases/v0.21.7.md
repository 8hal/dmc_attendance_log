# v0.21.7 — 배번·응원 보드에 실명

> **상태:** 배포 전. 태그는 배포가 성공한 뒤에만 `v0.21.7`.
> **이전 노트:** `v0.21.6`
> **앱 버전:** `cheer/bib.html`, `cheer/index.html`의 `<meta name="app-version" content="0.21.7">`. `noindex`는 유지한다. `cheer/waves.html`은 그대로다.

PATCH다. 대회 현장에서 자원봉사자가 선수를 구분할 수 있게, 배번 화면과 응원 보드에 실명을 보여 준다. 표시는 `닉네임 · 실명`이다. 실명이 없으면 닉네임만 보인다.

- 배번을 저장한 뒤, 또는 이미 배번이 있어 요약이 먼저 나올 때, 요약 카드 상단에 그 한 줄이 보인다. 데이터는 기존 `group-events` detail의 `participants[].realName`이다.
- 배번 입력 폼의 선수 표시(`#who`)에도 같은 한 줄이 나온다.
- 닉네임 선택 목록(`nick-btn`)은 닉네임만 보여 준다.
- 응원 보드의 코스 라벨, 순위, 같은 지점의 선수 고르기, 상세 기록에도 같은 한 줄이 보인다. `cheer-board`와 `cheer-runner` 응답의 선수 객체에 `realName`을 넣는다. 보드에 오르지 않는 참가자의 실명은 응답에 없다.
- 조는 이름만 보인다. 조 출발 시각은 나오지 않는다.

## 배포

Hosting만으로는 부족하다. 예전 `race` 함수의 응원 보드 응답에는 `realName`이 없다.

- 필요: `functions:race`, 그다음 `hosting`
- `functions-all`은 필요 없다. 스케줄 함수 동작은 바뀌지 않았다. Actions에서는 `functions-attendance-race`가 `attendance`와 `race`를 함께 올린다. 이 변경은 `race`만 해당한다.
- Storage 배포는 필요 없다.

```bash
firebase deploy --only functions:race --project dmc-attendance
firebase deploy --only hosting --project dmc-attendance
```

