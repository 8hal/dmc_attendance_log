## 1순위 검증 (토요일)

- 토요일(2026-10-31, 11월 1일 대회 전날) **오후 6시경** myresult 177 공식 API 엔드포인트가 정상 동작하는지 최종 확인한다.

- 알파벳 포함 검색(`A1037`, `A-1037`)은 결과 없음(이미 확인).

## 대안 1 (API 불능 시)

- 사용자가 입력한 **목표 페이스(목표 시간)** 데이터로 우선 운영한다.

## 대안 2 (배번 이슈)

- 실물 배번 형식: **조 알파벳 + 숫자** (예: `A-1037`). 앞 알파벳은 조 그룹, 뒤 숫자는 A조부터 연속 증가한다(H조까지 만 번대).
- myresult에 저장된 배번(`num`)은 **숫자만**이다.
- 숫자만 검색하면 조마다 같은 번호가 있어 다른 선수로 잘못 매칭될 수 있다.
- 알파벳 포함 검색은 myresult에서 결과 없음(확인됨).
- 숫자만으로 검색이 실패하면, 조 글자를 앞에 붙여 조합 조회하는 **폴백 코드**를 마련한다. 조합 키 조회 시 유니크하게 잡히는지 **토요일 확인에 포함**한다. 폴백 우선순위는 **낮게** 둔다.
- 앱 v0.21.10: 배번 입력은 숫자만. 전체 알파벳 입력 변경은 **보류**.
