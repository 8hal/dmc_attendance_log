# 춘백 S3 — `[팀]` 탭 시즌 결과 개편

**날짜:** 2026-10-23  
**상태:** 사용자 승인(2026-10-23). 구현함.  
**관련:** `docs/superpowers/specs/2026-10-22-chunbaek-season-report-design.md`

시즌3 출석은 2026-10-27에 끝난다.  
`[팀]`은 **2026-10-25(KST)부터** 시즌 결과 명단으로 바뀐다.  
그 전(96일차·10월 23일 포함)에는 주간 점·시즌 출석률 명단을 유지한다.

---

## 한 줄

`[팀]` 탭은 10월 25일부터 **누가 어떤 대회를 어떻게 달렸는지**를 보는 화면이다.  
그 전에는 출석 명단이다. 새 탭·새 API는 없다. `team-summary?includePhotos=1`만 성과 사진 보드가 쓴다.

---

## 1. 고른 방식

| 안 | 내용 | 결정 |
|----|------|------|
| **A. 결과 명단** | 상단을 등록/완주로 바꾸고, 한 줄 리스트에 사진+기록. 완주자는 빠른 순 | **이 안** |
| B. 사진 카드 | 큰 타일 격자 | 38명이면 스크롤만 길다. 개인 성과 하단 타일이 이미 사진을 모은다 |
| C. 순위판 | 1·2·3 메달, 시상대 | 동료 명단이 대회라 된다. 기록순만 쓰고 등수는 쓰지 않는다 |

이전 안(점에 둘째 줄만 더하기)은 폐기한다.

---

## 2. 화면

탭 이름 `[팀]`과 `#view-team`은 유지한다. 지금 제목은 `팀`만 있다. 그 아래 `<p class="section-sub">시즌 최종 결과</p>`를 더한다.

```
팀
시즌 최종 결과

┌─────────────────┬─────────────────┐
│ 결과 등록         │ 완주              │
│ 18명  38명 중     │ 15명              │
└─────────────────┴─────────────────┘

[사진] 김○○ · 나
       춘천 마라톤 완주 4:18:00 · 목표 달성 · PB

[사진] 이○○
       JTBC 서울마라톤 완주 4:05:00 · PB

[가]   최○○
       경주 마라톤 완주 4:57:00 · 목표 달성 · PB

[사진] 박○○
       춘천 마라톤 DNF

[정]   정○○
       목표 5:00 · 춘천 마라톤
```

상단 두 칸:

| 칸 | 값 | 캡션 |
|----|----|------|
| 결과 등록 | `status`가 `finisher` / `dnf` / `dns`인 인원 | `{전체}명 중` |
| 완주 | `status === "finisher"` 인원 | 없음 |

출석률·이번 주 3점·진행 바는 그리지 않는다.

---

## 3. 각 행

항상 같은 세 칸이다. 주간 점 칸은 없다.

```
[48px 아바타]  닉네임
               둘째 줄
```

아바타:

| 조건 | 그림 |
|------|------|
| `seasonResult.photoUrl` 있음 | 48×48, `object-fit: cover`, 모서리 4px |
| 없음 | 같은 크기 회색 칸. 닉네임 첫 글자. 빈 사진 아이콘은 넣지 않는다 |

둘째 줄 (`teamRowSecondLine`):

| `seasonResult` | 둘째 줄 |
|----------------|---------|
| 없음 또는 `status` 없음 | `목표 {m.goal} · {m.goalRaceLabel}` |
| `finisher` | `{raceLabel} 완주 {h:mm:ss}` |
| + `goalMet` | 뒤에 ` · 목표 달성` |
| + `pbAchieved` | 뒤에 ` · PB` |
| 둘 다 | ` · 목표 달성 · PB` (이 순서) |
| `dnf` | `{raceLabel} DNF` |
| `dns` | `{raceLabel} DNS` |

- 넷타임은 `formatNetTime` (`4:18:00`).
- `raceLabel`은 올린 대회. 온보딩 목표 대회가 아니다.
- 리스트에 `아직 결과 없음`을 쓰지 않는다. 미등록은 목표 줄을 둔다.
- 영문 Finisher / Net Time / 체중 / 소감 / 등수(`1위`)는 행에 없다.
- 나라면 닉네임 옆에만 ` · 나`.

예시:

- 김○○ 완주 15480초 목표+PB → `춘천 마라톤 완주 4:18:00 · 목표 달성 · PB`
- 이○○ 완주 14700초 PB → `JTBC 서울마라톤 완주 4:05:00 · PB`
- 박○○ DNF → `춘천 마라톤 DNF`

---

## 4. 정렬

등수 숫자는 없다. 순서만 이렇게 둔다.

1. 로그인한 나 (맨 위, 찾기 쉽게)
2. 완주: `netTimeSec` 오름차순. 같으면 닉네임 가나다
3. DNF, 그다음 DNS. 각 그룹 안은 가나다
4. 미등록: 가나다

필터(완주만 보기)는 없다.

이 순서는 클라이언트 `sortTeamMembersForDisplay`만 바꾼다. `team-summary` API의 멤버 순서는 지금처럼 닉네임이다.

---

## 5. 누르는 곳

행은 버튼 안에 버튼을 넣지 않는다.

```html
<div class="team-row" data-member-id="{id}">
  <button type="button" class="team-row-photo" aria-label="{닉네임} 기록 사진 보기">
    <!-- img 또는 이니셜 -->
  </button>
  <button type="button" class="team-row-main" aria-label="{닉네임} 프로필 보기">
    <strong>{닉네임}{나라면 · 나}</strong>
    <div class="team-goal">{둘째 줄}</div>
  </button>
</div>
```

| 대상 | 동작 |
|------|------|
| 사진 아바타 (`photoUrl` 있음) | `openLightbox([photoUrl])` |
| 이니셜 아바타 · 이름 · 기록 | `openTeamProfileModal` |
| 모달에서 결과 수정 | 없음. 개인 성과 페이지에서만 |

CSS: `.team-row`는 `48px 1fr`. `.team-row-main`은 한 칼럼(점이 없으므로 `1fr auto` 불필요).

---

## 6. 프로필 모달

출석 점수판이 아니게 바꾼다. `이번 주` 줄(점·3/3)은 뺀다.

순서:

| dt | dd |
|----|----|
| 시즌 최종 결과 | 리스트와 같은 문장. 미등록이면 `아직 없음` |
| 목표 대회 | 지금과 같음 |
| 풀 목표 | 지금과 같음 |
| 기존 PB | 지금과 같음 |
| 목표 몸무게 | 지금 공개 규칙 그대로 |
| 각오 | 지금과 같음 |
| 시즌 출석 | `{회}회 (출석률 {n}%)` — 숫자만. 점 없음 |

그 아래 **출석 메모·사진** 피드는 유지한다. 주간 점이 아니라 올린 사진·메모다.

모달에 기록증 썸네일은 넣지 않는다. 사진은 리스트 아바타에서 연다.

---

## 7. 개인 성과 타일과의 역할

| 위치 | 역할 | 이번 작업 |
|------|------|-----------|
| 개인 성과 맨 아래 타일 | 사진만 모아 보기 | 손대지 않음 |
| `[팀]` | 이름+기록 명단 | 이 스펙대로 개편 |

타일 → `[팀]` 링크는 넣지 않는다. 하단 탭이 있다.

---

## 8. 데이터

신규 HTTP action 없음. `GET team-summary`의 `members[]`만 쓴다.

| 필드 | 사용 |
|------|------|
| `seasonResult.status` | 등록/완주 집계, 둘째 줄, 정렬 |
| `raceLabel`, `netTimeSec` | 둘째 줄, 완주 정렬 |
| `photoUrl` | 아바타 + 라이트박스 |
| `goalMet`, `pbAchieved` | 둘째 줄 접미 |
| `goal`, `goalRaceLabel` | 미등록 둘째 줄 |
| `nickname`, `memberId` | 이름, 나 판별, 이니셜 |
| `seasonAttendCount`, `seasonAttendRate` | 모달 숫자만 |
| `weekDots`, `week`, `met`, `weekPhotoCount` | **팀 화면에서 그리지 않음** |

`note`와 체중은 행에 쓰지 않는다. 체중은 모달만, 지금 규칙.

미리보기 `MOCK.team`에 미등록 멤버 1명과 DNS 1명을 둔다. 지금 4명 모두 완주/DNF다. 테스트에서 DNF → DNS → 미등록 순을 잠근다.

---

## 9. 하지 않는 것

- 새 라우트, 새 탭, `이번 주 | 시즌` 스위치, 날짜 플래그로 출석/결과 이중 UI
- 주간 점, 이번 주 3점 칸, 시즌 출석률 칸
- 1·2·3 등수, 시상대, 완주만 필터
- 큰 사진 카드 격자
- 댓글·응원
- 신규 API
- 개인 성과 페이지 변경

홈 `[오늘]` 출석 체크는 시즌 종료일까지 그대로다. 이 스펙은 `[팀]`만 바꾼다.

---

## 10. 동의

이 개편은 **`[팀]`에서 출석 점을 빼고 시즌 결과 명단으로 바꾸는 것**이다.

이 방식으로 구현해도 되는가.
