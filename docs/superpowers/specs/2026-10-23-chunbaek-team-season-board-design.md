# 춘백 S3 — 팀원 성과 보드 설계

**날짜:** 2026-10-23  
**상태:** 기획안 (구현 전, 사용자 선택 대기)  
**관련:** `docs/superpowers/specs/2026-10-22-chunbaek-season-report-design.md`

---

## 1. 배경

개인 성과 페이지(`#view-report`)에서 대회 결과(완주 / DNF / DNS)와 기록 사진을 올린다.  
회원은 자기 결과만 보면 시즌 마감의 분위기가 약하다. **다른 팀원이 무엇을 달성했는지** 한눈에 보고 싶어 한다.

이미 있는 것:

- `GET team-summary`가 프로필 완료 회원마다 `seasonResult`(기록, 대회, `photoUrl`, `goalMet`, `pbAchieved`)와 시즌 출석을 내려준다.
- 개인 성과 페이지 맨 아래 **올라온 기록 사진** 타일(1번)이 이 API의 사진만 모아 보여 준다. 신규 action 없음.

없는 것:

- 팀원별 목표 대비 기록, 출석, 배지를 한 화면에서 비교하는 뷰.

---

## 2. 목표

1. 로그인 회원이 **같은 시즌 참가자**의 성과를 본다.
2. 한 장에 **기록 · 출석 · 사진**이 같이 보인다.
3. 신규 HTTP action을 만들지 않는다. `team-summary`를 재사용한다.
4. 체중은 개인 성과와 같이 **제외**한다.

---

## 3. 접근 3가지

### A안 (추천) — 기존 `[팀]` 탭을 시즌 마감 보드로 확장

지금 `[팀]`은 이번 주 3점과 목표 시간만 보여 준다. 시즌 마감이면 같은 탭에 **성과 카드 리스트**를 넣는다.

- 진입: 익숙한 `[팀]` 탭. 개인 성과 하단 사진 타일에서 「팀 성과 보기」로 이동할 수 있다.
- 각 카드: 닉네임, 대회, 완주 기록 또는 DNF/DNS, 목표 대비, 출석률, 기록 사진 썸네일.
- 정렬: 완주 기록 빠른 순 / 출석률 높은 순 / 가나다.
- 장점: 새 뷰·새 API 없음. 주간 보드와 시즌 보드를 한곳에서 전환.
- 단점: `[팀]`이 주간 출석과 시즌 결산을 같이 품는다.

### B안 — 개인 성과 옆에 `#view-report-team` 추가

`#/report-team` 전용 화면. 하단 탭은 `[나]` 또는 `[팀]`을 켠 채로 둔다.

- 장점: 개인 결산과 팀 결산이 역할이 분명하다.
- 단점: 뷰·라우트가 늘고, `[팀]`과 정보가 겹친다.

### C안 — 사진 타일만 키우고 팀 페이지는 나중에

1번 타일에서 라이트박스로 사진만 본다. 기록 비교는 다음 주.

- 장점: 가장 작다.
- 단점: “다른 팀원 성과를 본다”를 사진만으로 대신한다.

**추천: A안.** 데이터는 이미 `team-summary`에 있고, 회원은 `[팀]`을 알고 있다.

---

## 4. A안 화면

### 4.1 `[팀]` 상단

시즌 마감(또는 성과를 올린 사람이 1명 이상)이면 요약 숫자:

- 결과 등록 N / 참가 M명
- 완주 N명 · DNF · DNS
- 목표 기록 달성 N명 · PB 경신 N명
- 팀 평균 출석률 (기존)

주간 3점 요약은 **이번 주** 카드로 남긴다.

### 4.2 회원 카드

한 줄이 아니라 카드.

| 영역 | 내용 |
|------|------|
| 머리 | 닉네임, 나라면 `나` |
| 기록 | 완주 `4:25:48` / DNF / DNS / 아직 없음 |
| 비교 | 목표 대비, PB 여부. 체중 없음 |
| 출석 | 출석 일수 · 출석률 · 주 3점 달성 주 수 |
| 사진 | `photoUrl` 있으면 썸네일, 탭하면 기존 라이트박스 |

미등록 회원은 흐리게 「아직 결과 없음」.

### 4.3 정렬 · 필터

- 기본: 완주 기록 오름차순, DNF/DNS, 미등록
- 보조: 출석률, 가나다
- 필터(선택): 완주만 / 내 대회만

YAGNI: 댓글, 응원, 랭킹 시상대, 체중, 개인 기록 수정은 이 화면에 넣지 않는다.

---

## 5. 데이터

`GET team-summary` 기존 필드만 쓴다.

- `members[].seasonResult.{status,raceLabel,netTimeSec,photoUrl,goalMet,pbAchieved,note}`
- `members[].seasonAttendCount`, `seasonAttendRate`
- `members[].goalMarathonNetTime`, `goalRaceLabel`

서버 변경이 필요하면 **직렬화 누락 필드만** 보강한다. 새 action은 만들지 않는다.

사진 URL은 이미 토큰이 있는 Storage 주소다. 팀원끼리 보는 것은 출석 사진과 같다.

---

## 6. 개인 성과 하단 타일과의 관계

1번(구현): `#view-report` 맨 아래 사진 그리드. 탭하면 라이트박스.

A안이 되면 타일 아래 「팀에서 기록·출석 같이 보기」로 `[팀]`으로 보낸다.  
타일은 미리보기, `[팀]`이 본문이다.

---

## 7. 하지 않는 것

- 신규 API action
- 체중
- 운영진 전용 순위 발표 화면
- 사진 없는 회원을 빈 칸으로 채우기
- 외부 공유 OG 카드 (나중에)

---

## 8. 확인할 점

구현 전에 하나만 정하면 된다.

**팀원 성과는 어디에 둘까?**

1. A안 — 기존 `[팀]` 탭을 시즌 보드로 확장 (추천)
2. B안 — 개인 성과 옆 새 화면
3. C안 — 지금은 사진 타일만
