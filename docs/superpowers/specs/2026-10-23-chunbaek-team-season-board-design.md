# 춘백 S3 — `[팀]` 탭 시즌 결과 확장

**날짜:** 2026-10-23  
**상태:** 구현 전. 아래 **한 가지 방식**에 대한 동의 대기.  
**관련:** `docs/superpowers/specs/2026-10-22-chunbaek-season-report-design.md`

---

## 한 줄

`[팀]`을 새 화면으로 만들지 않는다.  
**지금 한 줄 명단에서, 결과를 올린 사람의 둘째 줄만 기록으로 바꾸고, 기록 사진이 있으면 왼쪽에 40px만 붙인다.**  
결과를 안 올린 사람은 지금 화면과 한 픽셀도 다르지 않다.

---

## 1. 지금 `[팀]` — 그대로 두는 것

화면 뼈대는 지금 `paintTeam()` 그대로다.

```
팀
┌─────────────────┬─────────────────┐
│ 시즌 출석률        │ 이번 주 3점        │
│ 68%  팀 평균      │ 12명  달성 · N명 중 │
└─────────────────┴─────────────────┘

김○○                              ●●●
목표 4:30 · 춘천 마라톤

이○○                              ●●○
목표 4:00 · JTBC 서울마라톤
```

| 유지 | 이유 |
|------|------|
| `#view-team` / `#team-summary` / `#team-list` | 새 뷰·새 탭 없음 |
| 상단 **2칸** (시즌 출석률 · 이번 주 3점) | 출석 요약은 그대로 |
| 행 그리드 `1fr auto` (이름+둘째 줄 \| 주간 점) | 출석 점이 오른쪽 |
| 첫째 줄 = 닉네임만 | `· 나` 같은 장식 없음. 나는 정렬로 맨 위 |
| 둘째 줄 = `목표 {시간} · {목표대회}` | 결과 없는 사람은 이 문장 유지 |
| 정렬 나 → 가나다 | 기록순 없음 |
| 행 탭 → 기존 프로필 모달 | 목표·각오·출석 피드 유지 |
| `GET team-summary` | 새 action 없음. `members[].seasonResult`는 이미 내려옴 |

**상단에 ‘결과 등록 N’ 칸을 더하지 않는다.** 칸이 늘면 출석 화면이 다른 페이지처럼 보인다.

---

## 2. 확장 방식 — 행에만 손댄다

손대는 곳은 두 곳뿐이다.

1. 리스트 행의 **둘째 줄 글** (결과 있는 사람만)
2. 리스트 행의 **왼쪽 40×40 사진** (`photoUrl` 있는 사람만)

결과를 한 명도 안 올리면 `[팀]`은 오늘과 **완전히 같다**.

```
팀
┌─────────────────┬─────────────────┐
│ 시즌 출석률        │ 이번 주 3점        │   ← 지금과 동일
│ 68%  팀 평균      │ 12명  달성 · N명 중 │
└─────────────────┴─────────────────┘

[사진] 김○○                           ●●●
       춘천 마라톤 완주 4:18:00 · 목표 달성 · PB

[사진] 이○○                           ●●○
       JTBC 서울마라톤 완주 4:05:00 · PB

[사진] 박○○                           ●●●
       춘천 마라톤 DNF

       정○○                           ●○○     ← 결과 없음. 지금과 동일
       목표 5:00 · 춘천 마라톤
```

---

## 3. 둘째 줄 문장 (이 표가 구현 계약)

`teamRowSecondLine(m)` 한 함수로 만든다. 영문 Finisher / Net Time / 체중 / 소감은 넣지 않는다.

| `seasonResult` | 둘째 줄 |
|----------------|---------|
| 없음 또는 `status` 없음 | **지금과 동일** `목표 {m.goal} · {m.goalRaceLabel}` |
| `finisher` | `{raceLabel} 완주 {h:mm:ss}` |
| `finisher` + `goalMet` | 뒤에 ` · 목표 달성` |
| `finisher` + `pbAchieved` | 뒤에 ` · PB` |
| 둘 다 | ` · 목표 달성 · PB` (이 순서) |
| `dnf` | `{raceLabel} DNF` |
| `dns` | `{raceLabel} DNS` |

시각:

- 넷타임은 기존 `formatNetTime` (`4:18:00`).
- `raceLabel`은 **실제 올린 대회** (`seasonResult.raceLabel`). 온보딩 목표 대회가 아니다.
- 리스트에 `아직 결과 없음`을 쓰지 않는다. 미등록은 지금 목표 줄을 유지한다.

예시 (목 데이터 기준):

- 김○○ `finisher` 15480초 목표달성+PB → `춘천 마라톤 완주 4:18:00 · 목표 달성 · PB`
- 이○○ `finisher` 14700초 PB만 → `JTBC 서울마라톤 완주 4:05:00 · PB`
- 박○○ `dnf` → `춘천 마라톤 DNF`

---

## 4. 왼쪽 사진

| 조건 | 화면 |
|------|------|
| `seasonResult.photoUrl` 있음 | 왼쪽 40×40, `object-fit: cover`, 모서리 4px. 빈 칸 자리 차지 |
| 없음 | **칸을 비워 두지 않는다.** 이름이 지금처럼 왼쪽부터 |

기록 없는 사람, 기록만 있고 사진 없는 사람 모두 빈 썸네일 없음.

---

## 5. 누르는 곳

지금 행은 통째로 `<button class="team-row">`다. 사진 탭을 넣으면 버튼 안에 버튼을 둘 수 없다. 행을 래퍼로 나눈다.

```html
<div class="team-row" data-member-id="{id}">
  <!-- photoUrl 있을 때만 -->
  <button type="button" class="team-row-photo" aria-label="{닉네임} 기록 사진 보기">
    <img src="{photoUrl}" alt="" width="40" height="40" />
  </button>
  <button type="button" class="team-row-main" aria-label="{닉네임} 프로필 보기">
    <div>
      <strong>{닉네임}</strong>
      <div class="team-goal">{둘째 줄}</div>
    </div>
    <div>{주간 점}</div>
  </button>
</div>
```

| 대상 | 동작 |
|------|------|
| `.team-row-photo` | 기존 `openLightbox([photoUrl])`. 그 사람 기록 사진 1장만 |
| `.team-row-main` (이름·기록·점) | 지금과 같이 `openTeamProfileModal` |
| 모달 안 기존 필드 | 그대로 |
| 모달 안 추가 1줄 | `시즌 최종 결과` / 리스트와 같은 문장. 미등록이면 `아직 없음` |
| 모달에서 결과 수정 | 없음. 수정은 개인 성과 페이지에서만 |

모달 `시즌 최종 결과`는 `이번 주` 다음에 둔다. 체중 공개 규칙은 지금과 같다. 모달에 기록 사진 썸네일은 넣지 않는다. 사진은 리스트에서 연다.

`#team-list` 위임 클릭은 `.team-row-main`만 프로필로 보낸다. `.team-row-photo`는 `stopPropagation` 후 라이트박스.

CSS:

- `.team-row` 래퍼: 사진 있으면 `40px 1fr`, 없으면 `1fr`. 썸네일을 늘리지 않는다.
- `.team-row-main`: 지금 `.team-row`와 같이 `1fr auto` (이름+둘째 줄 | 주간 점).

---

## 6. 정렬 · 필터

지금과 동일: 로그인한 나 맨 위, 나머지 닉네임 가나다.

하지 않는 것: 완주 빠른 순, 출석률 순, 완주만 보기, 시상대.

`[팀]`은 출석 동료 명단이다. 순위판으로 바꾸면 주간 점이 죽는다.

---

## 7. 개인 성과 사진 타일과의 역할

| 위치 | 역할 |
|------|------|
| 개인 성과 맨 아래 타일 | 사진만 모아 보는 미리보기. 유지. 이번 작업에서 손대지 않음 |
| `[팀]` 행 | 이름 + 기록 문장 + 주간 점. 누가 뭘 달렸는지 보는 본문 |

타일에서 `[팀]`으로 점프하는 링크는 넣지 않는다. 하단 탭이 이미 있다.

---

## 8. 데이터

신규 HTTP action 없음. `GET team-summary`의 `members[].seasonResult`만 읽는다.

| 필드 | 사용 |
|------|------|
| `status` | 완주 / DNF / DNS |
| `raceLabel` | 둘째 줄 대회명 |
| `netTimeSec` | 완주 넷타임 |
| `photoUrl` | 왼쪽 썸네일 + 라이트박스 |
| `goalMet`, `pbAchieved` | 둘째 줄 접미 |
| `goal`, `goalRaceLabel` | 미등록 둘째 줄 (지금과 동일) |
| `weekDots` / `weekPhotoCount` | 오른쪽 점 (지금과 동일) |

`note`(소감)와 체중은 행에 쓰지 않는다.

---

## 9. 하지 않는 것

- 새 라우트, 새 탭, `이번 주 \| 시즌 결과` 스위치
- 상단 3번째 칸 (`결과 등록 N`)
- 한 줄을 카드로 교체
- 기록순 랭킹
- 리스트에 `아직 결과 없음` / `· 나`
- 사진 없는 사람을 위한 빈 40px 칸
- 댓글·응원
- 체중
- 신규 API

---

## 10. 동의

이 확장은 **결과 있는 사람의 둘째 줄을 기록으로 바꾸고, 사진이 있으면 왼쪽에 붙이는 것**이다.

이 방식으로 구현해도 되는가.
