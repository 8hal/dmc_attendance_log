## What determines marathon performance (priority order)

1. **Aerobic endurance / durability** — weekly volume, long runs, time on feet, fatigue resistance after 25–30 km  
2. **Lactate threshold / marathon-pace economy** — sustained T-pace and MP blocks, especially on tired legs  
3. **VO2max / speed reserve** — supports MP; not the center of marathon prep once basic speed exists  
4. **Fueling, heat acclimation, strength, form** — tie-breakers and injury buffers  

**Pfitzinger ordering:** endurance → LT → VO2max. Long runs and tempo matter more than frequent 400 m repeats for marathon day.

## Periodization

### 3:1 loading (standard)

- **3 weeks** progressive load (volume or quality duration)  
- **1 week deload** −20–30% volume, same structure, slightly less quality duration  
- Repeat through base → build → peak  

### Phase goals (16–18 week A-race macro)

| Phase | Weeks (typical) | Volume | Emphasis |
|-------|-----------------|--------|----------|
| **Base** | 4–6 | 70–85 km | E/GA volume, introduce MLR, light LT |
| **Build** | 4–6 | 80–95 km | LT tempos, **MP blocks in long runs**, 1 VO2 every 1–2 weeks |
| **Peak** | 3–4 | 90–110 km | Longest long runs (**30–35 km**), longest MP segments (**12–20 km**), highest stress |
| **Taper** | 2–3 | −41–60% total | **A-race only** — volume down, intensity touches remain |

### Readiness gates (sub-3)

- 10K **sub-40:00** or strong tempo evidence at ~4:00–4:10/km  
- HM **sub-1:25** or predictions ~1:30 with heat-adjustment  
- **50–70 km/week** sustained before a specific sub-3 block  
- This athlete: HM pred **~1:30**, 10K pred **~40:35**, flat tempo **10 km @ 4:12–4:26** — **sub-3 is a stretch goal**, Cheorwon **3:0x is aligned** with current evidence

## Session types (definitions)

### Recovery (R)
Short, very easy. HR well below GA. Purpose: circulation, not mileage accounting.

### Easy (E)
True aerobic recovery between hard days. For this athlete often **6'30"–7'30"/km**, HR **<120**.

### General aerobic (GA) / MLR
**MLR = 12–16 km** at GA — “medium-long run.” Faster than E, slower than MP. Builds weekly fatigue without full long-run cost. **Pfitz signature session.**

### Tempo / LT (T)
Continuous or cruise intervals at threshold. Progress **duration before pace**. Typical progression: 20 min → 40 min → 6–8 km continuous at T.

### Marathon pace (M)
Goal race pace segments. Build **duration** across weeks: 2×5 km → 12 km continuous → 16–20 km in peak long runs.

**MP long-run examples (build → peak):**
- 24 km: last **8 km @ MP**  
- 28 km: last **12–16 km @ MP**  
- 32 km: last **8–10 km @ MP** (Pfitzinger-style fatigue-resistance)

### VO2 / intervals (I)
1000 m reps, 5×1 km, etc. **1× every 7–14 days** in marathon blocks — maintenance, not centerpiece.

### Long run (L)
- **Progressive long run (Pfitz):** start easy, drift toward **MP−10% to MP+20%**; last 5 km often **MP−10%**  
- **Hilly long (this athlete):** Namsan-style 20–28 km, +400–550 m — substitute flat volume with durability; don't stack with flat MP long same week  

---

## Long run rules

1. **Highest-value marathon session** — prioritize over extra easy volume.  
2. Not every long run is a race simulation; rotate **easy aerobic**, **progressive**, **MP finish**, **hilly**.  
3. **Do not** turn every long run into TE 5.0 — but **do not** cap every long run at 14 km for sub-3 candidates.  
4. After TE ≥4.5, next long run can be **shorter/easier** (16–20 km GA) — that's deload, not the default ceiling.  
5. Fast finish only when **prescribed** (MP block), not because athlete feels good.

## Taper — A-race vs B-race

### A-race (sub-3 peak) — Bosquet / RW / RunnersConnect

| Week out | Volume vs peak | Long run | Intensity |
|----------|----------------|----------|-----------|
| 3 | **85–90%** | 80–85% of peak LR | Keep LT/MP touches early in taper |
| 2 | **70–75%** | shorten | Short MP segments OK |
| Race week | **40–50%** | 8–10 km max | Strides, short MP touch optional |
| **Rule** | Cut **volume**, not **frequency** or **intensity identity** | | |

Marathon taper length: **19–22 days** common; meta-analysis sweet spot **2 weeks** at −41–60% volume.

### B-race (Cheorwon) — **no taper**

- **Do not** apply A-race taper (41–60% volume drop, multi-week rest).  
- Treat race as **the hardest training day of the week / micro-cycle** — a **42 km MP durability session**.  
- **Week before B-race:** maintain **~80–100%** normal volume and structure; only avoid **new** TE 5.0 long runs **3–4 days** before if legs are heavy.  
- **Day before B-race:** rest or 4–6 km easy — same as any hard Saturday.  
- **After B-race:** 3–7 days easy before resuming build (depends on race cost).  

**Error to avoid:** Giving B-race a 3-week taper → fitness loss and disrupted A-race build.

## Deload / absorption week (not taper)

When HRV suppressed, TE ≥4.5, or RPE 9/10:

- Volume **−20–30%** for **one week**  
- **Keep structure** (MLR can be 10–12 km GA; long run 16–20 km easy)  
- **No new quality** — optional maintenance strides  
- **Not** the same as race taper or “run 25 km total for the week”

## Planning anti-patterns (too-weak schedules)

The coach must **not**:

| Anti-pattern | Why wrong for this athlete |
|--------------|---------------------------|
| Weekly **<55 km** without injury/acute recovery | Already proven **70 km**; sub-3 path needs **80–95+** in build |
| **1 run day + rest** dominance | Needs **5–6 run days** for durability |
| Long run capped **≤14 km** every week | Peak needs **24–32 km** flat or **20–28 km** hilly |
| **Zero quality** for multiple weeks | Needs **weekly LT or MP** touch in build |
| **A-race taper** before Cheorwon | B-race — **maintain load** |
| “Smallest stimulus always wins” | Use **minimum effective dose**, not **minimum possible dose** |
| Ignore **Saturday key session** preference | Long/quality on **Saturday** |

**Minimum effective dose** = enough volume + specificity to drive adaptation while avoiding **repeated TE 5.0** in the same 10-day window without deload.

## Multi-race season (same macro cycle)

When **2–3 marathons** fall in one fall block:

| Role | Taper? | Typical goal |
|------|--------|--------------|
| **C / experience race** | **None** — normal or even reduced week; race itself is optional-effort | Finish safely, gather durability/fueling data; **no pace target, no reassessment gates** |
| **B / training race** | **No** — normal week, race = hard day | 42 km stimulus, pace diagnostic |
| **B+** (secondary peak) | Light micro only if **>21 days** to A-race | Sub-3 or strong MP — **trade-off vs A-race** |
| **A-race** | **Yes** — 2–3 weeks, −41–60% volume | PB / season peak |

**C-race rules (below B-race in commitment):**
- No taper, no pacing plan, no "reassess at 25/30 km to protect a time" logic — those only apply when a time target exists.
- Treat pacing as **run by feel / conversational-to-moderate**; any faster segment is opportunistic, not prescribed.
- Purpose is **experience + submaximal durability/fueling data**, not a diagnostic for goal-marathon pace. Don't use C-race splits to validate or invalidate MP fitness.
- Recovery days after a C-race can be **shorter** than after a B/A-race if the athlete kept effort genuinely easy (use actual HR/TE from the race, not the marathon distance alone, to size the recovery window).

**<21 days between marathons:** second race cannot be second full peak. Either first marathon is **controlled** (MP + 5–10 s/km) or second race is **downgraded** priority.
